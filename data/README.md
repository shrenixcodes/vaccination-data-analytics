# Data

## Source

This project uses the WHO/UNICEF immunization dataset published at
[immunizationdata.who.int](https://immunizationdata.who.int/global/wiisdatasetexplorer).
The portal provides five downloadable CSV extracts covering vaccination
coverage, disease incidence, reported cases, vaccine introduction, and
vaccine schedules.

Raw files are not committed to this repository (see `.gitignore`) because
redistribution terms are set by WHO. Download them from the portal above and
place them in `data/raw/` using the filenames below before running the
pipeline.

## Expected raw files

| File | Description |
|---|---|
| `coverage.csv` | Vaccination coverage by country, year, and antigen |
| `incidence-rate.csv` | Disease incidence rate by country, year, and disease |
| `reported-cases.csv` | Reported disease case counts by country and year |
| `vaccine-introduction.csv` | Year each vaccine was introduced, by country |
| `vaccine-schedule-data.csv` | National immunization schedule details |

Exact filenames are read from `src/config.py`; adjust there if the portal
exports different names.

## Processed data

`data/processed/` holds the cleaned, analysis-ready CSVs produced by
`src/data_cleaning.py`. These are regenerated by running the pipeline and are
documented in `docs/data_dictionary.md`.
